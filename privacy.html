プライバシーポリシー

PetReel Studioは、Ponが自身のペットの写真・動画とSNS投稿を管理するために使用する、本人専用のMacアプリです。本ポリシーはアプリと、この紹介サイトに適用します。

1. 取得するデータと目的

利用者が指定した写真・動画、撮影日時、素材の分析結果、投稿の企画・本文・字幕・予約時刻・公開履歴を扱い、素材整理、投稿制作、内容確認、公開管理に利用します。

GoogleログインとYouTube APIを通じて、次のデータを取得・利用します。

  • チャンネルのID・名前・ハンドル・アップロード一覧：接続先の確認と、本人の動画の管理。
  • 動画ID・タイトル・説明・公開状態・予約時刻：承認した動画のアップロード、予約の確認・変更・取消。
  • 視聴回数・高評価数・コメント数・共有数・平均視聴時間・登録者数の変化などの指標：投稿の振り返りと、本人向けの次の企画の作成。
  • 認証トークンと有効期限：本人が許可した範囲でAPIへの接続を継続。

要求するGoogleの権限は、YouTubeアカウントの管理（youtube）、YouTubeアカウントの表示（youtube.readonly）、YouTubeアナリティクスレポートの表示（yt-analytics.readonly）です。管理権限は広い権限ですが、アプリは動画削除の機能を提供しません。Googleのパスワードは取得しません。

2. 保存先と保護

Google・Instagram・Slackのトークンと接続の秘密情報はmacOSのキーチェーンに保存します。素材、投稿履歴、分析結果、取得した指標は、利用者のMac上のアプリ保存領域に保存します。紹介サイトへ送信・掲載することはありません。

アプリ専用のクラウドデータベースで、素材やGoogleトークンを保管する仕組みは設けていません。Mac本体と保存領域へのアクセスは、利用者のmacOSアカウントと端末の設定によって管理されます。

3. 外部サービスへの送信

  • Google / YouTube：API認証と、承認された動画・タイトル・説明・予約設定の送信に使用します。連携時にはチャンネルと指標を取得します。
  • Instagram / Meta：Instagramを接続した場合、承認された投稿・派生メディアを送信し、プロフィール・投稿の指標を取得します。
  • Anthropic / Claude：素材の縮小代表画像、素材の説明、キャラクター設定、投稿文、直近の投稿情報、動画の型・長さ・場面などで集計した視聴指標を、Claude CLIを通じて企画・採点・修正に使用するために送信します。GoogleやSNSの接続トークンは渡しません。送信データの処理には、利用者のAnthropic契約・設定・同社のポリシーが適用されます。
  • Slack：連携を有効にした場合、設定したチャンネルへ承認依頼・投稿本文・プレビュー・集計した週報を送り、返信とボタン操作を受け取ります。
  • Cloudflare R2：利用者が設定した場合、Instagramへ渡す公開用派生メディアを一時配置します。Mac内の原本や接続トークンを掲載するためには使用しません。

Googleユーザーデータを販売したり、広告配信・広告ターゲティングのために利用したりする機能はありません。PetReel StudioによるGoogle APIから取得した情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

4. 保存期間、連携解除、削除

接続トークンは連携を継続する間キーチェーンに保持します。アプリのYouTube設定で「ログアウト」すると、Googleへトークンの失効を要求し、Macのアクセストークンとリフレッシュトークンを削除します。失効要求に失敗した場合も、Mac内のトークンは削除されます。Googleアカウントの接続管理からもアクセス権を取り消せます。

ログアウトだけでは、Mac内の素材・投稿履歴・取得済み指標は削除しません。これらは利用者がアプリ保存領域から削除するまで保持されます。削除方法や保存先の確認は、下記窓口へお問い合わせください。外部サービスに送った投稿・Slackメッセージ・動画等は、各サービス側で別に管理・削除してください。

5. この紹介サイト

このサイトにログインフォーム、アクセス解析用スクリプト、広告は設置しません。GitHub Pagesで公開し、配信元のGitHubがセキュリティ等のためにIPアドレス等のアクセス情報を処理します。詳しくはGitHubのプライバシーステートメントをご確認ください。

6. 変更とお問い合わせ

データの扱いを変更する場合は、このページの更新日と内容を変更します。Googleユーザーデータの利用目的や共有範囲を拡張する場合は、追加の利用前に利用者の同意を求めます。
